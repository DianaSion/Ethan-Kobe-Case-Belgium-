# Public Witness Record — Belgium

## Overview

This repository is a public witness record of child separation following ignored technical complaints in Belgium. It is written in neutral, factual language and designed to be verifiable.

The record documents systemic failure, procedural violations, and retaliatory actions that resulted in the separation of children after technical assistance was requested. This exists because technical complaints were never investigated, the right to be heard was denied, temporary consent was converted into permanent separation, and decisions omit technical context entirely.

## Case Summary

This record preserves an immutable public record documenting:

- **Purpose**: Preserve dates, decisions, and the exact reasons authorities provided, alongside requests for due process and technical examination
- **Scope**: Public-safe summaries; minors' identifying data are not published
- **Verification**: The record is pinned to a published release
- **Principles**: No reset. No silence. No erasure.
